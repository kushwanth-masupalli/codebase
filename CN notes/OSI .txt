

The OSI model is a conceptual framework that standardizes how communication happens over a network, dividing it into 7 layers.

At the bottom, the physical layer transmits raw bits over wired or wireless media. The data link layer encapsulates bits into frames for node-to-node delivery using MAC addresses. The network layer handles logical addressing (IP) and routing between networks. The transport layer provides end-to-end communication using port numbers, with protocols like TCP for reliability and UDP for speed. The session layer establishes, manages, and terminates sessions. The presentation layer handles translation, encryption, and compression. Finally, the application layer provides network services to applications through protocols like HTTP and DNS.

As data moves down the layers, it gets encapsulated — each layer adds its own header — and this model is really useful for troubleshooting since it lets you isolate problems at specific layers.


TCP/IP model 

The main difference is that the OSI model has 7 layers while TCP/IP has 4. OSI is theoretical reference model used for teaching and standardization, TCP/IP is a practical implementation model that the actual Internet runs on. TCP/IP merges OSI's Session, Presentation, and Application layers into one Application layer, and combines Data Link and Physical into the Network Access layer. So when we say 'TCP/IP is what networks actually use,' it means protocols like IP, TCP, UDP, and HTTP operate within this 4-layer architecture.

1) what is deadlock ?

deadlock is a situation  where a set of proceess are permanenlty blocked because each process is waiting for a resource that is held by another process in the same set .as a result none of them can proceed.

2) Is deadlock the same as a process being blocked?

No.

A process can be blocked temporarily because it's waiting for I/O or a resource.

Deadlock means a group of processes are permanently waiting for each other, so no progress is possible unless the OS/intervention breaks the situation.


3) What are the four necessary conditions for deadlock ?

i) Mutual Exclusion : a least one resource must be non-sharable, meaning only one process can use it 
ii) Hold and Wait : a process is holding at least one resource while waiting to acquire another resource
iii) No preemption : a resource cannot be forcibly taken away from a process it must be release voluntarily 
iv) circular wait : a circular chain exits where every process is waiting for a resource held by the next process .

7) Stravation vs DeadLock 

this is another very common interview quesiton 

Deadlock

A set of processes are waiting for each other, and none can make progress.

Example:

P1 → waiting for P2
P2 → waiting for P1

Neither gets the resource.



Starvation

A process waits for an indefinitely long time because other processes continually get the resources or CPU before it.

Example:

P1 → low priority
P2 → high priority
P3 → high priority
P4 → high priority
P5 → high priority
...

P1 keeps getting ignored.

There doesn't have to be a cycle.

Key difference
Deadlock
→ Nobody in the deadlocked set can proceed.

Starvation
→ One process may wait indefinitely,
  while other processes continue making progress.
Solution for starvation

Aging.

Gradually increase the priority of a process the longer it waits.

------Disadvantages

4 ) What is a Page Table?

A page table is a data structure maintained by the operating system that maps each virtual page of a process to a physical frame in memory.

Why is the page table a performance problem?

The page table itself is stored in main memory.

Without optimization:

CPU
 ↓
Read page table from memory
 ↓
Read actual data from memory

That means two memory accesses for every instruction/data access.

To reduce this overhead, modern CPUs use a TLB.


What is TLB?
Interview answer

TLB, or Translation Lookaside Buffer, is a small, fast hardware cache that stores recently used page table entries to speed up virtual-to-physical address translation.

Instead of always accessing the page table in RAM:

CPU
 ↓
TLB
 ├── Hit → Get frame immediately
 └── Miss → Check page table in RAM
TLB Hit

The page mapping is already cached.

CPU → TLB → Physical Memory

Fast.

TLB Miss

The mapping isn't cached.

CPU
 ↓
TLB miss
 ↓
Page table in RAM
 ↓
Update TLB
 ↓
Physical memory

Slower.





5) What is Segmentation?

Segmentation is a memory management technique that divides a program into logical, variable-sized segments such as code, data, stack, and heap.

Unlike paging, segmentation reflects the logical structure of the program.



Example:

Program
+-------------+
| Code        |
+-------------+
| Data        |
+-------------+
| Heap        |
+-------------+
| Stack       |
+-------------+


Each segment has:

Base – starting physical address.

Limit – size of the segment.

The logical address is:

Segment Number + Offset

The segment table gives:

Segment
  ↓
Base + Limit

The offset must be less than the limit.


Advantages

Matches program structure.

Different protection can be applied to different segments.

Easy sharing of logical modules.

Disadvantage

Causes external fragmentation because segments are variable-sized.

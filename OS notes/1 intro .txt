3) Kernel mode vs User mode

modern operaitng system use different privilege levels to protect the system. the two most important modes are user mode and kernal mode

applications normally run in the user mode, where they have restricetd access to hardware and critical os resources. the kernel runs in the kernal mode with higher privilages and can direlclyt access hardware and protected memory . 

when an application needs a privileged operation ,such as reading a file, it makes a system call ,which causes a transition from user mode to kernel mode..

4) what is system call ?

a system call is the mechanism through which a user level application requests a service from the os system kernl 

applications normally cannot direcly perform privileged operations, so they user system calls to request services such as file access, process creating , memory management and netowrking 




4) OS as a resource manager 

an os acts as a resource manages because multiple processes may compete for limited resouces such as cpu time , memory , disk and i/o devices 

the os decides how these resources are allocated , when they are allocated and which process gets access to them . its goal is to use resouces efficienlty while maintainign fairness , isloation , and system performance .
